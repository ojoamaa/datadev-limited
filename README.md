# DataDev Limited Corporate Website — V1

A responsive, deployment-ready static corporate website for DataDev Limited.

## Included
- Universal DataDev corporate identity and SVG logo
- Responsive homepage and navigation
- Solutions, About, Platforms, Programme Capability, Sectors, Delivery Approach and Contact sections
- AGROW positioned as a flagship agriculture platform, not the corporate identity
- HelpNova, GuestNova and ComplianceWatch portfolio positioning
- VCN-relevant capability messaging without presenting unsupported client claims
- Mobile navigation and scroll reveal effects
- SEO description, favicon and Vercel config

## Run locally
Open `index.html` directly, or serve the folder with any static server.

Example with Python:
`python -m http.server 8080`

## Deploy
The site can be deployed directly to Vercel, Netlify, GitHub Pages, Render Static Sites or any normal web host.

## Before public launch
1. Replace the contact form demo handler with a real form backend or DataDev API.
2. Add official corporate email, phone and social links when confirmed.
3. Add CAC/company details if desired.
4. Replace any placeholder performance/impact statements with verified figures only.
5. Add privacy policy and terms if collecting personal data.
